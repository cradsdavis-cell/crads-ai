Rolling build of the Crads-AI app. It updates itself from here, so this is a one-time download.

**Windows:** download `crads-ai.exe` and double-click it. The build is unsigned, so Windows shows a blue "Windows protected your PC" box on first run: click **More info**, then **Run anyway**.

**Mac:** download `crads-ai-mac.zip`, double-click to unzip, then **right-click** Crads-AI.app and choose **Open** (the build is unsigned, so the first open needs the right-click; after that it opens normally).

On first run the app installs itself (Start menu + desktop icon on Windows, ~/Applications on Mac) and opens the setup screen. Every run after that opens your control panel or your dashboard. Everything runs locally, and your credentials go only to your own cloud providers.
