Set up my own

The real costs, before anything is made. The software is free and open source. What costs money is the machine it runs on and the AI inside it, and you pay both providers directly:

  • a Hetzner cloud server, roughly €4 to €30 a month depending on the size you pick, billed to you by Hetzner in euros
  • your own Claude subscription, billed to you by Anthropic
  • nothing to Crads-AI, ever

You need a Hetzner account and an API token; the next screen walks you through getting one. The token stays on this computer.

How to get one (about five minutes)
  1. Make a Hetzner account at console.hetzner.com if you do not have one. Sign up with your email, confirm it, and add a payment method. Hetzner sometimes asks new accounts to verify identity; if it does, that step is theirs and can take a little while.
  2. Create a project. On the Cloud console’s start screen choose “New project” and give it any name (“my-brain” is fine). If a default project is already there, that works too.
  3. Open the project, then in the left sidebar choose Security, then the API tokens tab.
  4. Generate the token. Press “Generate API token”, name it (“crads-ai” is fine), and set permissions to Read & Write. Read-only cannot build anything.
  5. Copy it straight away. Hetzner shows a token exactly once. Paste it below; if you lose it, just generate a new one and delete the old.

The token stays on this computer and is sent only to Hetzner’s own API. It is the key to your hosting project, so treat it like a password; you can revoke it any time from the same screen.
