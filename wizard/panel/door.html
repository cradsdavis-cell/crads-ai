Set up my own

Where should it live? The server is built in your own account at whichever hosting company you pick.

The real costs, before anything is made. The software is free and open source. What costs money is the machine it runs on and the AI inside it, and you pay both providers directly:

  • a cloud server, billed to you by the hosting company you picked
  • your own Claude subscription, billed to you by Anthropic
  • nothing to Crads-AI, ever

You need an account there and an API token; the next screen walks you through getting one. The token stays on this computer.

How to get one (about five minutes)
  1. Make a Hetzner account at console.hetzner.com if you do not have one. Sign up with your email, confirm it, and add a payment method. Hetzner sometimes asks new accounts to verify identity; if it does, that step is theirs and can take a little while.
  2. Create a project. On the Cloud console’s start screen choose “New project” and give it any name (“my-brain” is fine). If a default project is already there, that works too.
  3. Open the project, then in the left sidebar choose Security, then the API tokens tab.
  4. Generate the token. Press “Generate API token”, name it (“crads-ai” is fine), and set permissions to Read & Write. Read-only cannot build anything.
  5. Copy it straight away. Hetzner shows a token exactly once. Paste it below; if you lose it, just generate a new one and delete the old.

The token stays on this computer and is sent only to Hetzner’s own API. It is the key to your hosting project, so treat it like a password; you can revoke it any time from the same screen.

How to get one (about five minutes)
  1. Make a DigitalOcean account at cloud.digitalocean.com if you do not have one. Sign up with your email, confirm it, and add a payment method. New accounts are sometimes asked to verify identity; that step is theirs and can take a little while.
  2. Open API in the left sidebar of the control panel, then the Tokens tab, then Generate New Token.
  3. Name it (“crads-ai” is fine), pick an expiry you are comfortable with, and give it Full Access. Read-only cannot build anything.
  4. Copy it straight away. DigitalOcean shows a token exactly once. Paste it below; if you lose it, just generate a new one and delete the old.

The token stays on this computer and is sent only to DigitalOcean’s own API. It is the key to your account, so treat it like a password; you can revoke it any time from the same screen.

    Set up a team

    Each new person gets their own server and repository, and the company agent starts merging what they publish. Nobody else’s server is touched.

    What happens, in this order:

    1. Their personal/ folder is copied to this computer, for you to hand to them.
    2. Their server loses its keys to the company brain, and their repository is archived (kept, read-only).
    3. The company agent stops merging from them. What they already published stays in the company brain.
    4. Their server is deleted. This cannot be undone.

    You run this once, as the owner. It builds, in your own accounts:

    • a company brain: a private repository in your GitHub that every assistant on the team reads first
    • a company agent on its own server, the only thing that can write the company brain. Every night it merges what each person’s assistant learned, with sources, and writes a digest
    • an assistant for each person on their own server. Their private personal/ folder is never published

    The real costs: one server per person plus one for the company agent, billed to you by the hosting company; Claude for each person (company seats or their own plans, your choice), billed by Anthropic; nothing to Crads-AI, ever.

    Be straight with your team about one thing: you own the servers. Their personal/ folder is private from the company brain and from colleagues, not secret from you.

    Up to 15 people. Want an assistant for yourself too? Add your own name.

    The same token as “Set up my own” uses (read and write). It stays on this computer and is never stored.
