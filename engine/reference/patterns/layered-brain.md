## What it is

The brain is built from a small, fixed set of purpose-built modules (self, goals, business, network, workflow, and so on), each answering exactly one question about the person or the business. Nothing lives in two places, and every module has a clear owner-question, not a vague "notes" catch-all. Onboarding already builds this shape (the 11-module interview); this pattern is about keeping it that way afterward.

## Why it matters

Without clear module boundaries, note-taking degenerates into one file that keeps growing: this quarter's goal sits in the same paragraph as what happened last Tuesday. Every question becomes a search instead of a lookup, and updates land wherever the assistant happened to be looking when the fact came up, so the same fact quietly ends up stated two different ways in two different places. A new hire, or the assistant itself six weeks later, has to reconstruct "what's actually true" instead of reading one page.

## How to adopt it on this box

- Confirm each of the 11 onboarding modules (`wiki/self.md`, `wiki/business.md`, `wiki/network` (people pages), `wiki/goals.md`, `wiki/priorities.md`, `wiki/workflow.md`, `wiki/tools.md`, `wiki/voice.md`, `wiki/constraints.md`, `wiki/philosophy.md`, `wiki/north-star.md`, `wiki/past.md`) still has exactly one clear owner-question and isn't drifting into a catch-all.
- When a new fact surfaces in conversation, work out which single module owns it before writing anywhere. If it doesn't obviously belong to any existing module, that's a signal a new module or page is needed: propose it, don't force the fact into the nearest existing page.
- Cross-link related modules (e.g. a pricing change in `business.md` that also affects `priorities.md`'s quarter goal) rather than duplicating the fact in both.
- If a module hasn't been touched since onboarding and the business has clearly changed since (new offering, new season), flag it. See `freshness-staleness.md`.

## Signals you need it

- `business.md` (or any single module) keeps growing and starts reading like a diary.
- The assistant states a fact back to the client that conflicts with something on a different page.
- Answering "what's the plan for this quarter" requires reading several pages and reconciling them rather than reading one.
- A new person joining the business would have to ask a dozen questions the brain should already answer in one read.
